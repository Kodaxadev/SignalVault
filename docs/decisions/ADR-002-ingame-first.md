# ADR-002: In-Game-First Product Architecture

## Status

Accepted.

## Decision

Signal Vault will prioritize in-game object pages and quick capture over external dashboard features.

## Rationale

The product goal is to reduce tabbing out. Therefore, the first proof of value is:

- object dossier loads in-game
- player understands object context
- player logs Signal quickly

## Consequence

Graph view, rich editor, and admin workflows are secondary.
