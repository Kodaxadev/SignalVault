# Product Thesis

## One-Line Thesis

**Signal Vault is an in-game-first intelligence layer that turns EVE Frontier notes into actionable, entity-linked field Signals.**

## What Signal Vault Is

Signal Vault is:

- a field notebook
- an object dossier system
- a route/gate intelligence layer
- a storage and market memory system
- a tribe knowledge vault
- a confidence/staleness engine
- an in-game dApp surface for Smart Assembly context

## What Signal Vault Is Not

Signal Vault is not:

- a generic Notion clone
- a generic Obsidian clone
- a full map replacement
- a governance OS
- an intel marketplace first
- a smart-contract-first product
- a full route planner first
- a direct game client mod

## The Key Differentiator

Most tools will focus on maps, dashboards, governance, or marketplaces.

Signal Vault focuses on:

> Contextual memory at the point of in-game interaction.

When the player interacts with a gate, storage unit, turret, network node, market, system, or route, Signal Vault should answer:

1. What is this?
2. What do we know about it?
3. Who reported it?
4. How fresh is that intel?
5. Is the information verified, manual, stale, or contradicted?
6. What can I log right now?

## Product Wedge

Start with the underserved problem:

- quick in-game capture
- object-specific dossiers
- manual-first but verifiable later
- confidence and staleness
- anonymous/public fallback
- identity-aware publishing

Do not start by competing against map tools, governance systems, or intelligence marketplaces.
