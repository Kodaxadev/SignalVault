# Naming, Language, and Lore Fit

Signal Vault should feel native to the EVE Frontier universe. Avoid generic productivity-app language where possible.

## Product Name

**Signal Vault**

## Core Object

Generic: Note  
Signal Vault: **Signal**

## Tone

Use a practical, in-universe, tactical tone.

Signal Vault should feel like a survival-grade intelligence terminal, not a corporate SaaS dashboard.
