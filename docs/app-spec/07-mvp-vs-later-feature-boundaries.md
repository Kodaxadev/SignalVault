# MVP vs Later Feature Boundaries

## Purpose

Prevent scope creep while preserving the full product vision.

## v0.1 Must Build

### In-Game Shell

- `/ingame/object`
- UnknownObjectDossier
- compact UI

### Viewer Context

- anonymous state
- wallet/session placeholder
- access-code flow design/endpoint
- ViewerBadge

### Entity Resolution

- URL hint
- manual classification
- confidence badge
- unknown fallback

### Signals

- quick capture
- basic Signal list
- local draft storage
- private/public visibility
- context snapshots

### Dossiers

- object dossier
- gate dossier basic
- storage dossier basic
- market/system/route manual basics

### Support

- local storage
- export/import minimal
- staleness badge
- contradiction placeholder

## v0.1 Must Not Build

- graph view
- AI summaries
- direct map control
- full route planner
- full tribe governance
- smart contract writes
- intel marketplace
- screenshot attachments unless explicitly promoted
- complex operator claim system

## Phase 2+

- EVE dApp Kit wiring
- wallet/character resolution
- indexed/on-chain entity upgrades
- richer external app
- route/system aggregations

## Phase 3+

- tribe vault
- officer/scout-cell scopes
- audit log UI
- role management

## Phase 4+

- event/indexer corroboration
- map handoff
- Signal Bridge
- current system detection

## Phase 5+

- FrontierWarden policy integration
- sealed intel
- object operator pages
- public/paid intel packages
